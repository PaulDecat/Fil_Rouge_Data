# 🗳️ Analyse Élections Présidentielles 2002-2027

## 📋 Description

Application interactive de **data storytelling** pour analyser les résultats des élections présidentielles françaises (2002-2022) et simuler des scénarios pour 2027.

Réalisé dans le cadre d'un projet académique (Fil Rouge Data - Ynov).

---

## 🎯 Objectifs du projet

1. **Collecter** et nettoyer les données électorales (2002-2022)
2. **Analyser** les dynamiques régionales et socio-démographiques
3. **Modéliser** des scénarios prédictifs pour 2027
4. **Visualiser** de manière interactive

---
